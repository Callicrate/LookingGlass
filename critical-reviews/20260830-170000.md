## Scope and decision

This pass reviews whether the durable migration ledger proves the exact migration bytes that produced the local schema and data, not only the ordered version names. It covers source checkout and installed-wheel migration resources, DDL and DML-only edits, missing/extra files, rollback, backup/reopen, and legacy checksum adoption.

Applied migration bytes are release authority. A current binary must fail before new mutation when its known historical migration content disagrees with the store's durable provenance. Legacy stores may adopt current reviewed hashes only when their schema/ledger already match the recognized current migration chain; adoption must be atomic with normal startup validation.
