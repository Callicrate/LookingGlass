Existing cached facts may remain historical, but refresh/dispatch authority must come only from one completely reconciled desired snapshot. Presentation-readable views must reflect the repaired graph after commit and must not become an alternate write authority.

## Findings

### Finding 1: high, corrupted identity bridges authority generations

Status: closed.

A persisted identity row could be corrupted so its key matched desired fingerprint/root B while its binding still represented A. Raw identity lookup then reused the old system ID, overwrote the deterministic binding with B, and left A-admitted work ready to dispatch under B. Ordinary uncorrupted retargets already created a new generation; corruption bypassed that boundary.

Repair: generation selection now resolves only through `readable_configured_system_identities`, whose authority key is recomputed against readable binding settings. A mismatch allocates the deterministic B generation; reconciliation disables A and atomically cancels its action/intent work. The regression admits work under A, corrupts the identity, restarts under B, and proves a new system ID, predecessor cancellation, terminal receipt, `worker.run_once() == false`, and zero runner calls.

### Finding 2: medium, malformed bookkeeping timestamps preserve presentation/dispatch split

Status: closed.

Upserts preserved invalid `record_created_at` values. Readable views excluded the rows, while raw worker selection could still treat the rewritten authority fields as dispatchable.

Repair: before any identity lookup or bootstrap reconstruction, the outer configuration transaction canonicalizes created/updated bookkeeping across systems, identities, bindings, capabilities, and scopes. Valid updated times repair invalid creation times without reversing ordering. Reconcile reasserts desired-row creation times after upserts. A regression admits work, corrupts all five table families, restarts through repair, proves canonical rows and warning-free options, executes exactly one worker cycle/runner call, and reaches a terminal result.
