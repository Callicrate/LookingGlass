## Findings

### F1 — Medium: dynamic subprocess kwargs obscure platform call authority

A union-valued `process_options` dictionary was expanded into the overloaded `create_subprocess_exec` call, producing 13 diagnostics and making it impossible for static review to prove Windows receives only `creationflags` while POSIX receives only `start_new_session`.

Repair: use explicit OS branches with complete named calls. Runtime arguments, suspended Windows Job assignment, POSIX session ownership, and exception behavior are unchanged. Independent review clears the refactor.

### F2 — Low: heterogeneous normalization dictionaries erase exact field types

An `ObservationBatch(**base, ...)` dictionary inferred every base value as `str | UUID | datetime`, producing nine false call-shape diagnostics. Content artifacts also relied on an earlier mapping validator Pyright could not retain.

Repair: construct the batch with explicit named fields and repeat the bounded `Mapping` check at the content branch. The latter is defensive redundancy; it does not relax parsing or policy.

### F3 — Medium: stored JSON collections can iterate objects, keys, or characters

Capability target/facet/policy arrays, scope field masks, and policy text lists were decoded as `object` then used directly in membership/iteration. A corrupt JSON object or string could receive Python's accidental key/character iteration semantics instead of failing closed.

Repair: `_json_array` requires a JSON list; `_json_text_tuple` explicitly rejects every non-text element. Scope hydration, capability hydration, authorization, coverage validation, and policy iteration now use those typed helpers. This removes all general-iteration/operator diagnostics and strengthens corruption containment.

### F4 — Medium: malformed duplicate receipt IDs can be presented as accepted evidence

Exact and legacy duplicate paths converted `accepted_ids_json` with `tuple(_json_value(...))`. Objects became key tuples, strings became character tuples, and mixed arrays could reach a duplicate receipt.

Repair: decode once through `_json_text_tuple`; malformed prior IDs return `REJECTED` without digest backfill. Legacy semantic comparison keeps its existing false-on-malformed behavior. A regression corrupts an accepted batch to `{}` and proves replay rejection.

### F5 — Medium: Windows ACL inspection assumes a non-null ACE pointer

After successful `GetAce`, code immediately converted `ace.value` to `int`; the API type remains nullable and a null pointer would raise outside the controlled filesystem contract.

Repair: reject a null ACE pointer with a bounded `OSError`. Small POSIX capability helpers also model `geteuid`/`fchmod` truthfully on Windows stubs while retaining the same guarded runtime branches.

### F6 — Classified limitation: normalized DTO attributes retain constructor unions

The remaining diagnostics are dominated by DTO fields typed `str | UUID` for constructor compatibility even though `__post_init__` canonicalizes them to strings. Scattered `str(...)`, casts, or ignores would hide that input-versus-stored-attribute model rather than improve it. This round leaves the cluster explicit for a deliberate future contract typing design.
