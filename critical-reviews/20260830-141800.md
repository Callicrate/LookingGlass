## Scope and decision

This pass reviews how one malformed retained SQLite row affects unrelated cached reads, browser pages, startup recovery, and worker progress. It covers row-to-contract conversion for systems, objects, facets, relationships, intents, actions, attempts, operational events, and projected status records.

The decision boundary is explicit. Application identity, migration/schema shape, authority, and lease fences must fail closed. Historical diagnostics, terminal activity, and one object's cached projection should not take down unrelated healthy state when the offending row can be identified and rendered or quarantined safely. Repairs must remain bounded, redacted, and deterministic; silently inventing values for security or source authority is not acceptable.

## Findings

### Finding 1: high availability impact, one malformed list row collapses unrelated cached state

Status: closed.

Restart-retained probes showed that one malformed object timestamp, facet JSON payload, terminal action creation time, or alert occurrence time collapsed the dashboard or a complete history page. The dashboard returned its generic disconnected fallback and hid healthy systems; action and alert histories returned 503. Normal application writes reject these values, so the precondition is legacy/local/physical durable corruption rather than browser input.

Repair: migration `0024_corruption_containment` defines strict presentation-only views for objects, facets, relationships, action summaries/attempts/facet status, and operational events. Browser composition reads those views while domain, schema, authority, and lease paths retain strict base-table behavior. Query-local validators isolate malformed rows and set a process-local warning bit only when a page encounters one; there is no unbounded startup scan. The UI renders a nonblocking warning while healthy cached state remains visible.

### Finding 2: medium, one malformed attempt or relationship removes a healthy detail page

Status: closed.

A malformed attempt `started_at` made an otherwise valid action detail return 503. A malformed relationship `observed_at` made a parent object with a healthy sibling relationship return 503 while unrelated object pages remained available.

Repair: readable attempt and relationship views omit only the malformed child rows. A six-family restart regression retains the healthy attempt, child relationship, facet, action, alert, system, and object; all affected views carry the same integrity warning. A corrupt optional event link is nulled while the redacted alert itself remains visible.

### Finding 3: high, NULL text primary keys make queue poison unaddressable

Status: closed.

SQLite permits `NULL` in a non-integer `TEXT PRIMARY KEY` unless `NOT NULL` is explicit. A queued scope with `intent_scope_id=NULL` was selected forever because `WHERE intent_scope_id = NULL` never terminalized it. The action queue bounded each claim to 100 attempts but repeated the same unaddressable `action_id=NULL` row every poll, starving healthy work.

Repair: queue selection carries transaction-local SQLite `rowid` into quarantine only. A NULL public ID receives one surrogate UUID in the same transaction, the row terminalizes, and healthy work progresses. Rowid never becomes public identity or authority. Four migration triggers reject future NULL queue IDs. One-shot wrappers prove neither poison is selected twice.

### Finding 4: high, recursive retained JSON escapes quarantine

Status: closed.

Deep but syntactically valid retained JSON raised `RecursionError` outside both claim catch sets, leaving the head scope/action unchanged and repeatedly crashing supervision.

Repair: stored JSON parsing converts recursion failure into a bounded contract error and runs decoded values through the shared depth/container/node validator. Scope and action queue regressions place recursive poison before healthy work and prove one alert, one terminalization, and later claim progress.

### Finding 5: medium, malformed or divergent action links strand intents

Status: closed.

An admitted scope with a malformed/dangling `linked_action_id` failed every poll, while a missing or contradictory `action_intent_scopes` row could leave the parent open forever or permit an orphan action to execute.

Repair: startup reconciles both link representations. Malformed/dangling/contradictory active links reject the affected scope, remove stale join authority, refresh the aggregate directly by intent ID, and terminalize an active action only when it has no valid remaining parent. Action terminalization closes parents found through either representation. Rejected corrupt scopes render as “Stored scope unavailable” instead of reconstructing invented authority.

### Finding 6: medium, unknown retained states are invisible forever

Status: closed.

Rows whose state escaped the schema allowlist were selected by neither startup timing recovery nor normal claim queries, leaving intent aggregates open or actions outside dedupe/worker visibility.

Repair: startup recovery detects states outside the complete intent/action enums and terminalizes them through the same rowid-safe contract path. Existing exact lease/expiry/future-authority behavior remains unchanged.

### Finding 7: medium, cross-system relationships pass presentation containment

Status: closed.

A relationship with valid scalar fields and foreign keys could name a system-A parent, system-B child, and system-A relationship authority. The original readable relationship view accepted it, and object detail falsely rendered cross-authority containment without a warning.

Repair: readable relationships now require both the subject and child readable objects to share the relationship's system ID. The failed equality path invokes the same query-local corruption marker before excluding the row. The comprehensive restart regression includes a cross-system child beside one healthy and one malformed relationship and exposes only the healthy same-system child.
